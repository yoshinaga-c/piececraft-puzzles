# 🧩 PIECECRAFT
### Puzzles, Brain Teasers & Creative Challenges

**Every piece has a place. Every challenge tells a story.**

Welcome to **PIECECRAFT**, a puzzle-inspired brand created for curious minds, creative thinkers, and people who love the satisfaction of solving something extraordinary.

From beautifully illustrated jigsaw puzzles to intricate 3D constructions and challenging brain teasers, PIECECRAFT celebrates patience, imagination, discovery, and the joy of putting every piece together.

Our mission is simple: to make every moment of puzzling an opportunity to relax, learn, create, and explore.

## ✨ Our Vision

At PIECECRAFT, we believe puzzles are more than games. They are opportunities to disconnect from distractions, challenge our thinking, share meaningful moments, and discover the satisfaction of completing something piece by piece.

## 🚀 Getting Started

Once the storefront files have been added to this repository:

1. Clone or download the repository.
2. Open the project folder in your preferred code editor.
3. Review the HTML, CSS, JavaScript, and product data files.
4. Run the site using a local development server when needed.
5. Test the layout, images, product interactions, and navigation.
6. Publish the completed static site using GitHub Pages.

### Local Development

If the finished project loads product data using JavaScript `fetch()`, run it through a local server rather than opening `index.html` directly with a `file://` URL.

For Python installations, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## 🌐 Deployment with GitHub Pages

To publish the completed storefront:

1. Upload the project files to the repository's root directory.
2. Open the repository's **Settings** page.
3. Select **Pages** from the sidebar.
4. Choose **Deploy from a branch** under the build and deployment settings.
5. Select the `main` branch and the `/ (root)` folder.
6. Save the configuration and wait for deployment.

The published URL will generally follow this format:

`https://YOUR-USERNAME.github.io/piececraft-puzzles/`

Replace `YOUR-USERNAME` with your GitHub username. The actual URL depends on the repository and account configuration.
